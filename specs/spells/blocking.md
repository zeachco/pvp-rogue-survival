# Blocking (`blocking`)

**Source:** extractable buckler passive. **Activation:** reactive while enabled, with Rage upkeep of `0.001 * effective level` per second; successful blocks additionally spend any equipped buckler's calculated rage cost and start cooldown. **Effect:** each effective Blocking level adds one half percentage point of base block chance even without an equipped buckler, independently of buckler requirement effectiveness. An equipped buckler adds its own attribute-scaled block chance. The character sheet's Block chance row includes the passive contribution in both cases. A successful block prevents `min(incomingDamage, Strength)` under the shared resource and mitigation rules. Final block chance is capped at 100%. Base cooldown is 1 second; a Return buckler divides it by equipped-main-hand attacks per second, then the shared 3-to-1-second spell cooldown floor is applied.
