# Blocking (`blocking`)

**Source:** extractable buckler passive. **Activation:** reactive while a buckler is equipped, with Rage upkeep of `0.001 * effective level` per second; successful blocks additionally spend the buckler's calculated rage cost and start cooldown. **Effect:** each effective Blocking level adds one half percentage point of base block chance, independently of the buckler's requirement effectiveness. The character sheet's Block chance row includes this passive contribution. A successful block prevents `min(incomingDamage, Strength)` under the shared resource and mitigation rules. Final block chance is capped at 100%. Base cooldown is 1 second; a Return buckler divides it by equipped-main-hand attacks per second, then the shared 3-to-1-second spell cooldown floor is applied.
