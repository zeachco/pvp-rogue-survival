# Item Slow-Effect Contracts

Each item-applied slow must have its own file in this directory before implementation. Its contract must state the stable effect id, granting item source, affected unit, affected stat, multiplier or percentage, duration, stacking/refresh rule, requirement effectiveness, immunity/interaction rules, presentation, and tests.

There are currently no item-applied slow effects. Glacial Aura and Hindering Aura are spell passives and are specified in [their individual spell contracts](../spells/slow-aura.md) and [../spells/hindering-aura.md](../spells/hindering-aura.md). Whirlwind's self-slow is specified in [its spell contract](../spells/whirlwind.md). Freeze, attack wind-up, and attack recovery slow are mechanics, not item effects.
