# Animated character assets

`hero.glb` is Quaternius's `Enemy_EyeDrone`; `boss.glb` is `Enemy_Trilobite`.
Both come from the Standard edition of the **Sci-Fi Essentials Kit**:

- Source: https://quaternius.com/packs/scifiessentialskit.html
- Archive mirror: https://opengameart.org/content/sci-fi-essentials-kit
- License: CC0 1.0 Universal

The source glTF geometry, animation, and texture files were bundled and optimized
as standalone GLBs with glTF Transform. Only the two models used by the game are
redistributed here.
