# Animated character assets

`hero.glb` is Quaternius's `Enemy_EyeDrone`; `boss.glb` is `Enemy_Trilobite`;
`creep.glb` is `Enemy_QuadShell`. All three come from the Standard edition of
the **Sci-Fi Essentials Kit**:

- Source: https://quaternius.com/packs/scifiessentialskit.html
- Archive mirror: https://opengameart.org/content/sci-fi-essentials-kit
- License: CC0 1.0 Universal

`champion.glb` is Quaternius's `Robot Enemy Large` model:

- Source: https://poly.pizza/m/mPDR0L5uKx
- License: CC0 1.0 Universal

The source glTF geometry, animation, and texture files were bundled and
optimized as standalone GLBs with glTF Transform (WebP textures and
`KHR_mesh_quantization`). Only the four models used by the game are
redistributed here. See `ORBITING_HAMMER_LICENSE.md` and
`ROBOT_ENEMY_LICENSE.md` for the remaining asset licenses.
